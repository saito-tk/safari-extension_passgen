# 数値入力

## 対象

- 中央カラムの `文字数` 入力
- 中央カラムの `件数` 入力

## 基本方針

- 数値入力は編集中に範囲補正しない。
- 範囲補正は従来どおり、フォーカスが外れた時点または生成開始前に行う。
- 入力欄の近くに、現在入力できる範囲を小さく表示する。
- 範囲表示は入力カード内に置き、設定画面全体の密度を増やしすぎない。
- 範囲表示は補助情報であり、入力値より目立たせない。

## 範囲表示

### 文字数

- `文字数` カード内に `4〜999,999` のような範囲を小さく表示する。
- 文字数の範囲は固定値として扱う。

### 件数

- `件数` カード内に、現在の文字数から計算した件数範囲を小さく表示する。
- 件数の最小値は `1`、最大値は `1,000` とする。
- 件数の実際の上限は、現在の実装に合わせて `min(1000, floor(9999990 / 文字数))` とする。
- 文字数 `999,999` の場合、件数上限は `10` になる。
- 文字数の入力値が未確定の場合は、現在保存されている設定値をもとに範囲を表示する。

## ドキュメント同期

- 文字数、件数、動的上限などの仕様値は実装側を正とする。
- 仕様値を変更した場合は、`README.md`、`AGENTS.md`、`docs/design/`、関連する `docs/tasks/` の記述を同時に確認し、値の乖離を残さない。

## 全角数字の扱い

- 文字数と件数の入力欄に全角数字が入力された場合、半角数字へ変換して表示する。
- 変換対象は全角数字 `０`〜`９` とする。
- IME で全角数字を入力した場合は、入力確定後すぐに半角数字へ変換して表示する。
- 文字数と件数の保持値自体も半角数字へ正規化し、TextField 側の表示更新だけに依存しない。
- 全角数字から半角数字への変換は値の意味を変えない入力正規化として扱い、警告メッセージは出さない。
- 範囲外補正や空欄時の fallback は、従来どおりフォーカスが外れた時点で行う。

## 補正メッセージ

- 範囲外の文字数や件数を補正した場合、補正内容を警告メッセージとして表示する。
- 補正メッセージは一時的な案内として扱い、表示し続けない。
- `生成` ボタンを押したら、直前の補正メッセージは非表示にする。
- 文字数または件数の入力内容が変更されたら、直前の補正メッセージは非表示にする。
- 入力変更による非表示は警告メッセージだけを対象にし、生成不可などのエラーメッセージは別扱いとする。
