# アプリ設定

## 対象

- macOS メニューから開く設定画面
- アプリ外観設定
- パスワード生成画面の表示テーマ設定

## 基本方針

- 生成条件を操作する中央カラムには、生成に直接関係する設定を置く。
- 見た目だけに影響する設定は、設定画面に集約する。
- `アプリテーマ` は macOS のライト / ダーク / システム追従を切り替える設定として維持する。
- `表示テーマ` は生成画面のアクセントカラーを切り替える設定として扱い、生成ロジックには影響させない。

## 表示テーマ

- `表示テーマ` は設定画面の `アプリテーマ` セクションの下側に配置する。
- 中央カラムには `表示テーマ` セクションを表示しない。
- 表示テーマの選択 UI は、従来と同じ色スウォッチ方式を維持する。
- 選択中の表示テーマは、スウォッチの選択状態で分かるようにする。
- 表示テーマを変更したら、開いている生成画面にも反映する。
- 表示テーマは既存の `NativePasswordSettings.theme` に保存し、既存ユーザーの設定互換性を維持する。
