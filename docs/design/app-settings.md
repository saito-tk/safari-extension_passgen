# アプリ設定

## 対象

- macOS メニューから開く設定画面
- アプリ外観設定
- パスワード生成画面の表示テーマ設定

## 基本方針

- 生成条件を操作する中央カラムには、生成に直接関係する設定を置く。
- 見た目だけに影響する設定は、設定画面に集約する。
- `アプリテーマ` は macOS のライト / ダーク / システム追従を切り替える設定として維持する。
- `表示テーマ` は生成画面のアクセントカラーを切り替える設定として扱い、生成ロジックには影響させない。

## 表示テーマ

- `表示テーマ` は設定画面の `アプリテーマ` セクションの下側に配置する。
- 中央カラムには `表示テーマ` セクションを表示しない。
- 表示テーマの選択 UI は、従来と同じ色スウォッチ方式を維持する。
- 表示テーマが増えても設定画面の幅を圧迫しないよう、スウォッチは複数行に折り返して表示する。
- 選択中の表示テーマは、スウォッチの選択状態で分かるようにする。
- 表示テーマを変更したら、開いている生成画面にも反映する。
- 表示テーマは既存の `NativePasswordSettings.theme` に保存し、既存ユーザーの設定互換性を維持する。

## テーマ一覧

- デフォルトは `青` とする。
- 少なくとも以下のテーマを提供する。
  - 青
  - 緑
  - ティール
  - ミント
  - シアン
  - インディゴ
  - 紫
  - ラベンダー
  - ピンク
  - ローズ
  - オレンジ
  - 黄色
  - グレー

## 配色方針

- ライトモードは白いパネルを基調にし、背景色は淡い色味に抑える。
- ダークモードでは、すべてのテーマで背景とパネルを低彩度に寄せ、アクセント色だけでテーマ差が分かるようにする。
- ダークモードのアクセント色は高彩度・高輝度に寄せすぎず、ボタン、選択枠、バッジが画面上で強く光りすぎない範囲にする。
- 青と緑も他テーマと同じ明度・彩度の範囲に収め、先頭のテーマだけが浮いて見えないようにする。
- 表示テーマの選択中スウォッチは、非活性状態に見えないよう、チェックマークや明確な選択リングで表す。
- 黄色、オレンジ、ピンク、赤系は特に目立ちやすいため、ダークモードでは彩度を落とした暖色として扱う。
- 文字色と補助文字色は、テーマごとの色味より可読性を優先する。
