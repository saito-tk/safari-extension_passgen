# 生成結果コピー表示 仕様

## 目的

生成結果一覧で、どのパスワードを一度コピーしたかを行単位で分かるようにする。

## 対象

- メイン画面右カラムの生成結果一覧
- 各パスワード行のコピーアイコンボタン

## 表示仕様

- 各結果行の右側にコピーアイコンボタンを表示する。
- コピーアイコンボタンを押すと、その行のパスワード全文をクリップボードへコピーする。
- 一度コピーした行のコピーアイコンボタンには、コピー済みを示すチェックマークを重ねて表示する。
- チェックマークは、現在表示中の生成結果一覧に対する状態として扱う。
- 新しく生成し直して結果行が入れ替わった場合、コピー済み状態も新しい結果行の状態に従う。
- チェックマークが付いたあとも、コピーアイコンボタンは有効なままにし、同じ行を再度コピーできる。
- コピー済み表示は視覚的な目印であり、パスワード本文、強度評価、テキスト出力内容には影響しない。

## 文言

- コピー済み状態はチェックマークで示す。
- 行内に `Copied!` のような一時文言を追加表示しない。
