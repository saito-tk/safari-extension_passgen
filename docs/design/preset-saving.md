# プリセット保存機能 仕様

## 目的

左カラムで現在の生成設定に名前を付けて保存し、保存済みプリセットを一覧から選択すると中央カラムの設定値へ反映できるようにする。

## 対象画面

- メイン画面左カラム
  - 上部: プリセット名入力と保存操作
  - 下部: 保存済みプリセット一覧
- メイン画面中央カラム
  - プリセット選択時に設定値が反映される対象

## UI

### 左カラム上部

- 見出しは現行の `保存済み設定` を維持する。
- 見出し直下にプリセット名入力欄を置く。
- 入力欄の近くに保存ボタンを置く。
- 保存ボタンは以下の条件で無効化する。
  - 生成中
  - 入力欄が空、または空白だけ
- 入力欄は生成中に無効化する。
- 保存完了、入力エラー、保存エラーは左カラム内の短いステータス文言で表示する。

### 左カラム下部

- 保存済みプリセットを縦リストで表示する。
- 一覧上部にソート選択 UI を置く。
- ソート条件は以下を持つ。
  - 名前
  - 作成日
  - 更新日
- ソート方向は以下を持つ。
  - 昇順
  - 降順
- 各行は通常、プリセット名だけを表示する。
- ソート条件が `作成日` の場合は、プリセット名に加えて作成日を表示する。
- ソート条件が `更新日` の場合は、プリセット名に加えて更新日を表示する。
- 選択中のプリセットはテーマ色で分かる表示にする。
- 選択中のプリセットを再度選択すると、選択解除する。
- 保存済みプリセットが 0 件の場合は空状態を表示する。
- プリセット選択は生成中に無効化する。

## 保存対象

保存対象は、パスワード生成に影響する中央カラムの設定とする。

- 文字数
- 件数
- 文字種の有効/無効
- 大文字の個別選択状態
- 小文字の個別選択状態
- 数字の個別選択状態
- 記号の個別選択状態
- 生成方式
- 似た文字の除外
- 選択した文字種を必ず含める
- 同じ文字を連続させない設定
- 先頭文字の設定
- 除外文字

テーマはアプリ全体の見た目設定なので、プリセット保存対象に含めない。

## 先頭文字設定の保存ルール

先頭文字の設定は、選択中のモードに必要な値だけを保存する。

- `文字種` モードの場合
  - `firstCharacterMode = characterSet` を保存する。
  - `allowUppercaseFirst`
  - `allowLowercaseFirst`
  - `allowDigitsFirst`
  - `allowSymbolsFirst`
  - `fixedPrefix` は保存しない。
- `固定文字` モードの場合
  - `firstCharacterMode = fixedPrefix` を保存する。
  - `fixedPrefix` を保存する。
  - `allowUppercaseFirst`
  - `allowLowercaseFirst`
  - `allowDigitsFirst`
  - `allowSymbolsFirst` は保存しない。

読み込み時は、保存されていない側の値を現在値や古い値から復元しない。必要な場合は安全な初期値を使う。

## 保存形式

- `UserDefaults` に JSON で保存する。
- 既存の現在設定 `nativePassgenSettings` とは別キーで保存する。
- 保存キーは `nativePassgenPresets` とする。
- データ構造は配列とし、表示順も配列順とする。

各プリセットは以下を持つ。

- `id`: UUID 文字列
- `name`: 表示名
- `createdAt`: 作成日時
- `updatedAt`: 更新日時
- `settings`: プリセット用設定スナップショット

## 名前ルール

- 保存時に前後空白と改行を除去する。
- 空名は保存しない。
- 同名が存在する場合は、既存プリセットを上書きする。
- 上書き時は `id` と `createdAt` を維持し、`updatedAt` と `settings` を更新する。
- 新規保存後または上書き後、そのプリセットを選択状態にする。
- プリセット選択中に保存した場合は、選択中プリセットを更新する。
- プリセット未選択時に保存した場合は、同名プリセットがあれば上書きし、なければ新規作成する。
- 選択中プリセットの更新時は、入力欄の名前でプリセット名も更新する。
- 選択中プリセットの更新時は、`id` と `createdAt` を維持し、`updatedAt` と `settings` を更新する。

## 読み込み動作

- プリセット行を選択すると、保存された設定を現在設定へ反映する。
- プリセット未選択状態からプリセットを選択する直前に、その時点の現在設定を一時的に保持する。
- 選択中のプリセットを再度選択して選択解除した場合は、保持していた現在設定へ戻す。
- 反映後は既存の現在設定保存にも同期する。
- 反映時は `lengthText` と `countText` も更新する。
- 反映時は記号の全選択状態と文字種有効フラグを再同期する。
- 反映時は生成結果を消さない。
- 生成中は選択できない。

## ソート動作

- 保存済みプリセット一覧は、選択中のソート条件と方向に従って表示する。
- 名前ソートはプリセット名のローカライズ比較で行う。
- 作成日ソートは `createdAt` を使う。
- 更新日ソートは `updatedAt` を使う。
- 初期ソートは `名前` の昇順とする。
- ソートは表示順だけを変え、保存済み配列の永続化順には影響しない。

## 互換性と補正

- プリセット読み込み時は、現在設定復元と同じ上限/下限補正を行う。
- 文字種配列の長さが現行定義と異なる場合は安全な既定値へ補正する。
- 記号数が変わった場合も安全な既定値へ補正する。
- 保存済みプリセットの復元に失敗した場合は空配列として扱い、アプリ起動を妨げない。

## 非対象

この実装では以下を扱わない。

- プリセットの削除
- 別名保存と更新保存のボタン分離
- 外部ファイルへのプリセット export/import
- テーマのプリセット保存
