# プリセット保存機能 仕様

## 目的

左カラムで現在の生成設定に名前を付けて保存し、保存済みプリセットを一覧から選択すると中央カラムの設定値へ反映できるようにする。

## 対象画面

- メイン画面左カラム
  - 上部: プリセット名入力と保存操作
  - 下部: 保存済みプリセット一覧
- メイン画面中央カラム
  - プリセット選択時に設定値が反映される対象
  - 上部見出しに現在のプリセット状態を表示する

## UI

### 左カラム上部

- 見出しは現行の `保存済み設定` を維持する。
- 見出し直下にプリセット名入力欄を置く。
- 入力欄の近くに保存ボタンを置く。
- 保存ボタンは以下の条件で無効化する。
  - 生成中
  - 入力欄が空、または空白だけ
- プリセット未選択時は、名前が入力されていれば `保存` を有効化する。
- プリセット選択中は、ボタン表示を `更新` にする。
- プリセット選択中の `更新` は、以下のいずれかがある場合だけ有効化する。
  - 入力欄の名前が選択中プリセット名と異なる。
  - 現在の設定が選択中プリセットの保存内容と異なる。
- プリセット選択中でも、名前と設定が選択中プリセットの保存内容と同一なら `更新` は無効化する。
- ロック中のプリセットを選択している場合、保存ボタンは `ロック中` と表示し、常に無効化する。
- 入力欄は生成中に無効化する。
- 保存完了、入力エラー、保存エラーは左カラム内の短いステータス文言で表示する。

### 左カラム下部

- 保存済みプリセットを縦リストで表示する。
- 一覧上部にソート選択 UI を置く。
- ソート条件は以下を持つ。
  - 名前
  - 作成日
  - 更新日
- ソート方向は以下を持つ。
  - 昇順
  - 降順
- 各行は通常、プリセット名だけを表示する。
- 各行には、プリセット名に加えて生成条件の短い要約を 2 行で表示する。
  - 表示例:
    - `文字数 16`
    - `条件 94字 / 4種`
  - 文字数は保存されたパスワード長を表示する。
  - 件数はプリセット一覧では表示しない。
  - 条件要約は、保存された文字種・個別文字選択・記号選択・似た文字除外を反映した実効文字セット数とカテゴリ数を使う。
  - 固定文字や先頭文字制限は条件要約の文字セット数には含めず、生成に使える全体文字セットの目安として表示する。
- ソート条件が `作成日` の場合は、プリセット名に加えて作成日を表示する。
- ソート条件が `更新日` の場合は、プリセット名に加えて更新日を表示する。
- 選択中のプリセットは未選択行より明確に分かる表示にする。
  - テーマ色の背景を未選択行より強くする。
  - テーマ色の左アクセントバーまたは同等に目立つ選択マーカーを表示する。
- 選択中を示す文言ラベルは表示しない。
- プリセット行は、設定ボタンを除く行全域を選択/選択解除のクリック対象にする。
- 選択中のプリセットを再度選択すると、選択解除する。
- 各プリセット行には設定ボタンを置く。
- 設定ボタンから `削除` を選べる。
- 設定ボタンから `ロック` / `ロック解除` を選べる。
- 一覧上部にプリセット import/export 操作を置く。
- ロック中のプリセット行には、名前の近くに鍵アイコンを表示する。
- 保存済みプリセットが 0 件の場合は空状態を表示する。
- プリセット選択は生成中に無効化する。

### 中央カラム上部

- 中央カラム上部の見出しは、現在の設定状態を表示する。
- プリセット未選択時は `未保存の設定` と表示する。
- プリセット選択中は、選択中プリセット名を表示する。
- プリセット選択中にプリセット名入力欄を変更しても、保存または更新が確定するまでは見出しのプリセット名は変えない。
- 選択解除または選択中プリセット削除後は `未保存の設定` に戻す。

## 保存対象

保存対象は、パスワード生成に影響する中央カラムの設定とする。

- 文字数
- 件数
- 文字種の有効/無効
- 大文字の個別選択状態
- 小文字の個別選択状態
- 数字の個別選択状態
- 記号の個別選択状態
- 生成方式
- 似た文字の除外
- 選択した文字種を必ず含める
- 同じ文字を連続させない設定
- 先頭文字の設定
- 除外文字

テーマはアプリ全体の見た目設定なので、プリセット保存対象に含めない。

## ロック動作

- ロックは、保存済みプリセットの生成設定を誤って変更しないための保護である。
- ロック状態はプリセットごとに保存する。
- ロック中でも、プリセット一覧からの選択、選択解除はできる。
- ロック中のプリセットは削除できない。
- ロック中のプリセットで削除を選んだ場合、確認ダイアログは出さず、左カラム内のステータス文言で `ロック中のため削除できません。` と表示する。
- ロック中のプリセットを選択している間は、中央カラムの文字選択と生成ルールを編集不可にする。
  - 文字種の有効/無効
  - 大文字/小文字/数字/記号の個別選択
  - 記号貼り付け反映
  - 生成方式
  - 似た文字の除外
  - 選択した文字種を必ず含める
  - 同じ文字を連続させない設定
  - 先頭文字の設定
  - 除外文字
- 文字数と件数は、今回の生成用の一時的な指定として扱い、ロック中のプリセットを選択している間も変更できる。
- ロック中に文字数や件数を変更しても、プリセット更新ボタンは `ロック中` 表示のまま有効化しない。
- ロック中のプリセットを選択している間は、更新ボタンを `ロック中` 表示にし、名前や設定が保存内容と異なっても有効化しない。
- ロック中のプリセットを選択解除した場合は、選択前の未保存設定へ戻り、未保存設定は通常どおり編集できる。
- 未選択時にロック中プリセットと同名で保存する場合は、既存プリセットのロック保護を優先し、上書きせずエラーを表示する。
- ロック解除後は、通常の更新・同名上書き対象に戻る。

## 先頭文字設定の保存ルール

先頭文字の設定は、選択中のモードに必要な値だけを保存する。

- `文字種` モードの場合
  - `firstCharacterMode = characterSet` を保存する。
  - `allowUppercaseFirst`
  - `allowLowercaseFirst`
  - `allowDigitsFirst`
  - `allowSymbolsFirst`
  - `fixedPrefix` は保存しない。
- `固定文字` モードの場合
  - `firstCharacterMode = fixedPrefix` を保存する。
  - `fixedPrefix` を保存する。
  - `allowUppercaseFirst`
  - `allowLowercaseFirst`
  - `allowDigitsFirst`
  - `allowSymbolsFirst` は保存しない。

読み込み時は、保存されていない側の値を現在値や古い値から復元しない。必要な場合は安全な初期値を使う。

## 保存形式

- `UserDefaults` に JSON で保存する。
- 既存の現在設定 `nativePassgenSettings` とは別キーで保存する。
- 保存キーは `nativePassgenPresets` とする。
- データ構造は配列とし、表示順も配列順とする。

各プリセットは以下を持つ。

- `id`: UUID 文字列
- `name`: 表示名
- `createdAt`: 作成日時
- `updatedAt`: 更新日時
- `isLocked`: ロック状態
- `settings`: プリセット用設定スナップショット

## 外部ファイル export/import

- プリセット一覧は JSON ファイルとして export/import できる。
- export/import は生成中に無効化する。
- export 操作では、現在保存されているプリセットから複数選択で export 対象を選ぶ。
- export 対象が 0 件の場合は export できない。
- export ファイルの拡張子は `.json` とする。
- export ファイル名の既定値は `passgen-presets-YYMMDDHHmm.json` とする。
- export JSON は次の外形を持つ。
  - `format`: 固定文字列 `passgen.presets`
  - `version`: 整数 `1`
  - `exportedAt`: export 日時
  - `presets`: `NativePasswordPreset` の配列
- アプリ内には export JSON の形式バージョンごとの読み込み処理を保持する。
- import 時は `format` と `version` から JSON 形式を判定し、対応している形式だけ読み込む。
- 現行 export 形式は `version = 1` とする。
- 将来 JSON 形式を変更する場合は、現行形式の読み込み処理を残し、新しい version 用の読み込み処理を追加する。
- 過去の JSON に軽微な差分がある場合は、取り込める範囲で現行形式へ正規化する。
  - `format` が欠落していても `presets` 配列を持つ場合は、旧形式候補として扱う。
  - `version` が欠落していても `presets` 配列を持つ場合は、旧 version 1 候補として扱う。
  - 旧形式候補でも、プリセットや設定値の検証に失敗する場合は import しない。
- import 時は JSON の外形、必須キー、型、値域、UUID 形式、日時、プリセット設定の配列長を検証する。
- JSON 形式または値が不正な場合は 1 件も import せず、左カラム内のステータス文言で失敗を表示する。
- 正しい export JSON は import できるよう、現在のプリセット復元と同じ設定補正を import 時にも適用する。
- import 対象に既存プリセットと同じ UUID が含まれる場合は、そのまま import せず警告を表示する。
- 重複 UUID がある場合の警告では、別名で import するか、import をキャンセルするかを選べる。
- 別名で import する場合、重複したプリセットは UUID を再発行し、既存名と衝突しない名前へ変更して追加する。
- UUID が重複していないプリセットは、保存済み一覧へ追加する。
- import 後はプリセット一覧の永続化データを更新する。
- import では現在選択中のプリセット状態と現在設定を変更しない。

## 名前ルール

- 保存時に前後空白と改行を除去する。
- 空名は保存しない。
- 同名が存在する場合は、既存プリセットを上書きする。
- 同名の既存プリセットがロック中の場合は上書きしない。
- 上書き時は `id` と `createdAt` を維持し、`updatedAt` と `settings` を更新する。
- 新規保存後または上書き後、そのプリセットを選択状態にする。
- プリセット選択中に保存した場合は、選択中プリセットを更新する。
- プリセット未選択時に保存した場合は、同名プリセットがあれば上書きし、なければ新規作成する。
- 選択中プリセットの更新時は、入力欄の名前でプリセット名も更新する。
- 選択中プリセットの更新時は、`id` と `createdAt` を維持し、`updatedAt` と `settings` を更新する。
- 選択中プリセットの更新後は、更新後の名前と設定を最新の比較基準にする。

## 読み込み動作

- プリセット行を選択すると、保存された設定を現在設定へ反映する。
- プリセット未選択状態からプリセットを選択する直前に、その時点の現在設定を一時的に保持する。
- 選択中のプリセットを再度選択して選択解除した場合は、保持していた現在設定へ戻す。
- 反映後は既存の現在設定保存にも同期する。
- 反映時は `lengthText` と `countText` も更新する。
- 反映時は記号の全選択状態と文字種有効フラグを再同期する。
- 反映時は生成結果を消さない。
- 生成中は選択できない。

## ソート動作

- 保存済みプリセット一覧は、選択中のソート条件と方向に従って表示する。
- 名前ソートはプリセット名のローカライズ比較で行う。
- 作成日ソートは `createdAt` を使う。
- 更新日ソートは `updatedAt` を使う。
- 初期ソートは `名前` の昇順とする。
- ソートは表示順だけを変え、保存済み配列の永続化順には影響しない。

## 削除動作

- プリセット行の設定ボタンから `削除` を選択すると、確認ダイアログを表示する。
- 確認ダイアログでは削除対象のプリセット名を表示する。
- 確認ダイアログで削除を確定した場合のみ、プリセットを削除する。
- 削除対象がロック中の場合は削除せず、確認ダイアログも表示しない。
- ロック中の削除操作は `ロック中のため削除できません。` と表示する。
- 削除後はプリセット未選択状態へ戻す。
- 削除対象が選択中だった場合は、選択前設定への復元は行わず、削除直前の現在設定を維持する。
- 削除後はプリセット一覧の永続化データを更新する。
- 生成中は削除できない。

## 互換性と補正

- プリセット読み込み時は、現在設定復元と同じ上限/下限補正を行う。
- 文字種配列の長さが現行定義と異なる場合は安全な既定値へ補正する。
- 記号数が変わった場合も安全な既定値へ補正する。
- 保存済みプリセットの復元に失敗した場合は空配列として扱い、アプリ起動を妨げない。

## 非対象

この実装では以下を扱わない。

- 別名保存と更新保存のボタン分離
- テーマのプリセット保存
