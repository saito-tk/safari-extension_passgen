# 生成中止

## 対象

- 中央カラム上部の `生成` ボタン
- 生成中のパスワード生成タスク

## 基本方針

- アプリ起動時点では自動生成しない。
- `生成` ボタン押下時のみ生成を開始する。
- 生成中も生成ボタンは押下可能にする。
- 生成中の生成ボタンは `停止` と表示し、押下すると現在の生成を中断する。
- `停止` 押下後、キャンセル完了までの間はボタンを `停止中...` と表示し、再押下できないようにする。
- 生成中は、生成ボタン以外の設定系 UI は従来どおり非活性にする。
- 長い生成でも UI が固まりにくいよう、生成処理は分割して進める。
- 中止要求後は、次のキャンセル確認タイミングで生成を停止する。
- 中止処理中も設定系 UI は非活性のままにする。

## 中止後の結果

- 中止前に生成済みの結果は一覧に残す。
- 進捗は中止時点の件数を表示する。
- 中止後は設定系 UI を再び操作可能にする。
- 中止後はテキスト出力やコピーを、残っている生成済み結果に対して利用できる。
- 中止により生成IDは作り直さない。中止された生成で残った結果を出力する場合も、その生成開始時に発行した生成IDを使う。

## メッセージ

- 中止後、生成結果欄に「生成を中止しました。」という案内を表示する。
- エラーではなくユーザー操作による中断として扱う。
- 中止前に 1 件も生成されていない場合は、結果一覧は空のままにする。

## 数値入力との関係

- 生成開始前には従来どおり、文字数と件数の範囲補正を行う。
- 文字数と件数の入力欄では、全角数字の入力確定後すぐ半角数字へ正規化する。
- 全角数字の正規化は入力値の意味を変えないため、警告は表示しない。
