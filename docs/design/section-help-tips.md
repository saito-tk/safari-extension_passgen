# 画面内 tips

## 対象

- 左カラムの `保存済み設定`
- 中央カラムの `文字選択エディタ`
- 中央カラムの `生成ルール`
- 右カラムの `生成結果` 強度評価

## 基本方針

- tips は、そのセクションで何を設定するのかをユーザー目線で説明する。
- 専門用語だけで説明せず、実際に何が変わるのかを短く書く。
- tips は通常操作を妨げないポップオーバーとして表示する。
- 既存の右カラム強度評価 tips と同じ `?` アイコンボタンを使う。
- 同じ内容を本文 UI に常時表示して画面密度を上げない。

## 保存済み設定 tips

- 現在の文字数、件数、文字選択、生成ルールをプリセットとして保存できることを説明する。
- プリセット選択中に設定や名前を変えた場合、保存ボタンは既存プリセットの更新になることを説明する。
- プリセット一覧から選ぶと、そのプリセットの設定が中央カラムへ反映されることを説明する。
- 選択中のプリセットをもう一度選ぶと選択解除され、選択前の未保存設定へ戻ることを説明する。
- ソートは名前、作成日、更新日で切り替えられることを説明する。
- 各行の設定ボタンから削除でき、削除時は確認ダイアログが出ることを説明する。
- 各行の設定ボタンからロックでき、ロック中は選択できるが生成設定と更新を変更できないことを説明する。
- テーマはアプリ全体の見た目設定なので、プリセットには含まれないことを説明する。

## 文字選択エディタ tips

- 生成に使える文字を、文字種ごとに選べることを説明する。
- 選択を外した文字は生成候補に入らないことを説明する。
- 記号は個別選択でき、貼り付けから反映できることを説明する。
- `現在選択中の文字` は、最終的に候補に入る文字の確認欄であることを説明する。

## 生成ルール tips

- `完全一様` は選んだ文字からできるだけ公平に選ぶ方式で、細かい条件より偏りの少なさを優先することを説明する。
- `ルール優先` は、先頭文字や必ず含める文字種などの条件を反映しやすい方式であることを説明する。
- `似た文字を除外する` は読み間違えやすい文字を避ける設定であることを説明する。
- `選択した文字種を必ず含める` と `同じ文字を連続させない` は `ルール優先` で有効になることを説明する。
- `先頭文字の設定` は、先頭に使える文字種を選ぶか、固定文字を先頭に付ける設定であることを説明する。

## 表現ルール

- tips の文章は、日本語として自然で、技術的知識がない人にも意味が分かることを優先する。
- `候補`、`条件`、`固定文字` などの必要な用語は使ってよいが、用語の意味が想像できる文脈を添える。
