# パスワード強度表示 仕様

## 目的

生成結果ごとに、総当たり耐性だけでなく推測されやすいパターンも加味した強度の目安を表示する。

## 対象画面

- メイン画面右カラム
  - 生成結果一覧
  - 各生成結果の強度ラベル、推定 bits、補助情報

## 評価方針

- 既存の推定 entropy、ユニーク文字数、文字出現バランス評価を維持する。
- `zxcvbn` の考え方に沿って、推測されやすいパターンの検出結果も評価に加える。
- 外部ライブラリは追加せず、アプリ内で完結する軽量なパターン検出として実装する。
- パターン検出は補助的な評価とし、暗号学的に安全な乱数生成そのものは変更しない。

## パターン検出

以下のパターンを検出対象にする。

- よく使われる単語、サービス名、パスワード由来語
- 連続文字列
  - `abc`
  - `cba`
  - `123`
  - `321`
- キーボード配列由来の連続文字列
  - `qwerty`
  - `asdf`
  - `zxcv`
- 同一文字の長い繰り返し
- 短い文字列ブロックの繰り返し
  - `ababab`
  - `abcabc`
- 日付らしい数値列
  - `YYYYMMDD`
  - `YYMMDD`

## 評価への反映

- パターンが検出された場合は強度スコアを下げる。
- 検出されたパターンは補助メッセージに表示する。
- 複数のパターンが検出された場合は、それぞれを加味してスコアを下げる。
- パターンが検出されない場合は、従来の entropy、variety、balance を中心に評価する。

## 表示

- 既存の `Basic`、`Good`、`Strong`、`Very Strong` のラベルは維持する。
- `Variety` と `Balance` の表示は維持する。
- パターン検出による減点の目安として `Pattern` 指標を表示する。
- パターン検出結果は既存の補助メッセージに含める。
- `推定 xxx bits` は理論上の総当たり耐性として維持し、パターン検出による減点後スコアとは区別する。

## 制約

- 実装は Swift / SwiftUI の標準機能で完結させる。
- 生成処理が UI を固めないよう、評価処理は生成済みの各パスワードに対して軽量に行う。
- 判定は目安であり、漏洩データベース照合やオンラインチェックは行わない。
