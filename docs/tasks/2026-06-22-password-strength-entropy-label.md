# 強度評価の推定エントロピー表示名を見直す

## 背景

生成結果一覧の上側に表示している `bits` は、強度評価の内部値としては妥当だが、ユーザー向け表示としては意味が伝わりにくい。単なる数値ではなく、何を表しているかが分かる表示名にする。

## タスク

- [x] 強度評価仕様に、表示名を `推定エントロピー: xxx bits` とする方針を追記する。
- [x] README の強度表示説明を同じ表記に更新する。
- [x] 生成結果一覧上部の表示を `推定エントロピー: xxx bits` に変更する。
- [x] 強度評価 tips の表示ラベルを `推定エントロピー` に変更する。
- [x] Xcode build で確認する。

## 受け入れ条件

- 生成結果一覧の上側に `推定エントロピー: 112 bits` のような形式で表示される。
- tips を読んだときに、`bits` 単独ではなく `推定エントロピー` として意味が分かる。
- パスワード行ごとには推定エントロピーを繰り返し表示しない。
