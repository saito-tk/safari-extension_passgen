# 生成結果一覧への生成ID表示

## 背景

テキスト出力ファイル名には生成IDの短縮版を含めているが、アプリ画面上では現在の生成結果セットのIDを確認できない。出力ファイル名と画面上の結果を対応づけやすくするため、生成結果一覧にも短縮IDを小さく表示する。

## タスク

- [x] `docs/design/text-export.md` に生成IDの画面表示仕様を追加する。
- [x] `docs/design/password-strength-analysis.md` に生成結果共通メタ情報として生成IDを追記する。
- [x] `README.md` に生成IDの画面表示を追記する。
- [x] 生成結果一覧の共通メタ情報に `生成ID: shortid` を表示する。
- [x] 生成結果が空の場合は生成IDを表示しない。
- [x] Xcode build で確認する。

## 確認観点

- 生成後、生成結果一覧の上側に短縮生成IDが表示される。
- テキスト出力のデフォルトファイル名に含まれる短縮IDと、画面上の生成IDが一致する。
- 生成結果がない状態では生成IDが表示されない。
