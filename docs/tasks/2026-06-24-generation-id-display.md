# 生成結果一覧へのハッシュ表示

## 背景

テキスト出力ファイル名には生成結果セットの短縮ハッシュを含めているが、アプリ画面上では現在の生成結果セットのハッシュを確認できない。出力ファイル名と画面上の結果を対応づけやすくするため、生成結果一覧にも短縮ハッシュを小さく表示する。

## タスク

- [x] `docs/design/text-export.md` にハッシュの画面表示仕様を追加する。
- [x] `docs/design/password-strength-analysis.md` に生成結果共通メタ情報としてハッシュを追記する。
- [x] `README.md` にハッシュの画面表示を追記する。
- [x] 生成結果一覧の共通メタ情報に `ハッシュ: shortid` を表示する。
- [x] 生成結果が空の場合はハッシュを表示しない。
- [x] Xcode build で確認する。

## 確認観点

- 生成後、生成結果一覧の上側に短縮ハッシュが表示される。
- テキスト出力のデフォルトファイル名に含まれる短縮ハッシュと、画面上のハッシュが一致する。
- 生成結果がない状態ではハッシュが表示されない。
