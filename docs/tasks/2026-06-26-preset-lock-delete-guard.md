# ロック中プリセット削除防止 実装タスク

## 背景

プリセットロックは保存済み内容を誤って変更しないための保護である。削除も取り消しにくい破壊的操作なので、ロック中プリセットでは削除確認へ進まず、ロック中のため削除できないことを表示する。

## タスク

- [x] `docs/design/preset-saving.md` にロック中プリセットの削除不可仕様を追加する。
- [x] `README.md` と tips 仕様のロック説明を更新する。
- [x] ロック中プリセットで `削除` を選んだ場合、確認ダイアログを出さない。
- [x] ロック中プリセットで `削除` を選んだ場合、`ロック中のため削除できません。` を表示する。
- [x] `deletePreset` 側でもロック中プリセットを削除しない。
- [x] Xcode build で確認する。

## 確認観点

- ロック中プリセットのメニューから削除を選んでも、確認ダイアログが表示されない。
- ロック中プリセットのメニューから削除を選ぶと、左カラムに `ロック中のため削除できません。` が表示される。
- ロック解除後は従来どおり確認ダイアログを経て削除できる。
