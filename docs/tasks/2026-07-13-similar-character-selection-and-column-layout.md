# 似た文字の個別除外とカラム幅調整 実装タスク

## 目的

似た文字を除外する設定で除外対象を個別に選べるようにし、保存済み設定サイドバーを切り替えてもウィンドウサイズを変えずに中央・右カラムを再配分する。

## タスク

- [x] 設定画面で `パスワードの保護` をテーマ設定より上に移動する。
- [x] 設定画面で `O/o/0` と `I/l/1` の各文字を個別に除外対象へ選べるUIを追加する。
- [x] 個別の除外対象をアプリ設定へ保存し、プリセットには保存しない。
- [x] サイドバー表示切替でウィンドウサイズを変更しないようにする。
- [x] サイドバー切替後も文字選択エディタの10列レイアウトを維持する。
- [x] Xcode build で確認する。
