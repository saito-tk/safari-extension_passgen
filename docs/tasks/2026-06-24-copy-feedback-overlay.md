# コピー直後フィードバックの固定表示

## 背景

コピー済みチェックマークは、どの行を一度コピーしたかの目印として有効だが、クリック直後にコピー処理が完了したことを伝える表示としては弱い。一方で、`Copied!` のような通常レイアウト内の文言を出すと、結果行の高さが変わって一覧が揺れる。

## タスク

- [x] `docs/design/result-copy-feedback.md` に高さを変えない一時フィードバック仕様を追記する。
- [x] コピー直後に `コピーしました` の一時フィードバックを表示する。
- [x] 一時フィードバック表示で結果行の高さが変わらないようにする。
- [x] チェックマーク表示後も同じボタンから再度コピーできる状態を維持する。
- [x] Xcode build で確認する。

## 確認観点

- コピー直後に `コピーしました` が短時間表示される。
- `コピーしました` の表示/非表示で結果行の高さが変わらない。
- コピー済みチェックマークは引き続き残る。
- チェックマークが付いた行でも、再度コピーできる。
