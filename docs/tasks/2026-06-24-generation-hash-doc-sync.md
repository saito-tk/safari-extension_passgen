# 生成ハッシュ表記の関連ドキュメント同期

## 背景

生成結果識別子を `生成ID` から `ハッシュ` 表記へ変更したあと、停止仕様や過去タスクの説明に古い `生成ID` 表記が残っていた。現行仕様と読む人向けの説明がずれないよう、関連ドキュメントの用語を同期する。

## タスク

- [x] `docs/design/generation-cancel.md` の停止後の識別子説明を `ハッシュ` 表記に更新する。
- [x] 生成結果一覧表示に関するタスク記録の本文を現行の `ハッシュ` 表記へ更新する。
- [x] テキスト出力ファイル名に関するタスク記録の本文を現行の `ハッシュ` 表記へ更新する。

## 確認観点

- 現行仕様として参照される説明で、画面表示ラベルが `生成ID` のまま残っていない。
- 停止後に同じ生成結果セットのハッシュを使うことが分かる。
