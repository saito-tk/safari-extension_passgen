# 生成結果メタ情報の共通表示タスク

## 背景

生成結果の `bits` と `条件` は、同じ生成条件から作られたパスワードでは全件共通になる。各パスワード行に同じ情報を繰り返すと、一覧の表示密度が下がり、パスワードごとの違いがある情報のように見える。

また、`条件` はプリセットの性質を見分ける補助情報としても有用なため、プリセット一覧に短く表示する。

## タスク

- [x] 強度評価仕様に、`bits` と `条件` を生成結果一覧の上側に共通表示する方針を追記する。
- [x] プリセット仕様に、プリセット行へ条件要約を表示する方針を追記する。
- [x] 生成結果行から `bits` と `条件` チップを削除する。
- [x] 生成結果一覧の上側に、生成バッチ共通の `bits` と `条件` を表示する。
- [x] プリセット一覧の各行に `条件 n字/m種` を表示する。
- [x] README の強度表示説明を更新する。
- [x] Xcode build で確認する。

## 完了条件

- 生成結果の各行には `総合`、`長さ`、`耐性` と警告メッセージだけが表示される。
- `bits` と `条件` は、生成結果一覧の上側に 1 回だけ表示される。
- プリセット一覧では、名前ソート時でも各プリセットの条件要約が表示される。
- 作成日/更新日ソート時は、条件要約と日付情報の両方が読める。
