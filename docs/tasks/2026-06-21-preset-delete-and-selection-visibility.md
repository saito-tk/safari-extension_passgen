# プリセット削除と選択表示改善 実装タスク

## 対応仕様

- `docs/design/preset-saving.md`

## 目的

プリセット一覧で選択中の行を分かりやすくし、各プリセットの設定ボタンから確認ダイアログ付きで削除できるようにする。

## 作業タスク

- [x] 選択中プリセット行の背景、枠線、左アクセント、ラベルを強化する。
- [x] プリセット行に設定ボタンを追加する。
- [x] 設定ボタンのメニューから `削除` を選択できるようにする。
- [x] 削除確認ダイアログを表示する状態を ViewModel または View に追加する。
- [x] 確認ダイアログで削除確定時だけプリセットを削除する。
- [x] 削除後はプリセット未選択状態に戻す。
- [x] 選択中プリセットを削除した場合は削除直前の現在設定を維持する。
- [x] 削除後に `UserDefaults` のプリセット一覧を更新する。
- [x] TODO に進捗を反映する。
- [x] `xcodebuild -project xcode/Passgen/Passgen.xcodeproj -scheme Passgen -configuration Debug build` で確認する。

## 完了条件

- プリセット一覧で選択中の行がひと目で分かる。
- 各プリセット行の設定ボタンから削除を選べる。
- 削除前に確認ダイアログが出る。
- 削除確定後、対象プリセットが一覧から消える。
- 削除後はプリセット未選択状態になる。
