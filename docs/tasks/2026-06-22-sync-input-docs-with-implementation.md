# 入力仕様ドキュメントを実装値に同期する

## 背景

現在の実装では、文字数は `4`〜`999,999`、件数は `1`〜`1,000`、件数上限は `min(1000, floor(9999990 / 文字数))` で計算している。一方で README とリポジトリガイドには、過去仕様の件数上限と古い計算式が残っていた。

今後は実装側を正とし、仕様値やユーザー向け挙動を変更した場合は関連ドキュメントも同時に更新する。

## タスク

- [x] README の文字数・件数仕様を実装値へ同期する。
- [x] AGENTS.md の入力仕様を実装値へ同期する。
- [x] docs/design の数値入力仕様へ、件数上限と計算式を明記する。
- [x] 今後の仕様変更時に関連ドキュメントの乖離を残さないルールを追記する。
- [x] ドキュメント内に古い件数上限や古い計算式が残っていないことを確認する。

## 受け入れ条件

- README、AGENTS.md、docs/design の入力仕様が、現在の実装値と一致している。
- 古い件数上限を正とする記述が残っていない。
- 今後の仕様決定時に README など関連ドキュメントを更新する方針が明記されている。
