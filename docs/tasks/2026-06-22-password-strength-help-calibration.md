# パスワード強度評価 tips と判定補正 実装タスク

## 対応仕様

- `docs/design/password-strength-analysis.md`

## 目的

強度評価 tips の情報不足を解消し、結果行の短縮ラベルと評価軸の意味を分かるようにする。あわせて、長いランダム生成結果で偶発的な短いパターンや一般語断片により `既知リスク` や `推測されにくさ` が過度に下がる判定を補正する。

## 作業タスク

- [x] 強度評価 tips に結果行ラベルの対応表を追加する。
- [x] 強度評価 tips に各評価軸の主な判定基準を追加する。
- [x] 100 文字省略表示の注記を各パスワード行から結果一覧上部の共通注記へ移す。
- [x] `既知リスク` を blocklist 全体一致、単純派生、支配的な一般語に基づく判定へ補正する。
- [x] `推測されにくさ` をパターンの有無だけでなく、全体に占める割合で判定する。
- [x] 長いランダム文字列中の短い偶発一致では `既知リスク` と `推測されにくさ` を大きく下げない。
- [x] README の強度表示説明を更新する。
- [x] `xcodebuild -project xcode/Passgen/Passgen.xcodeproj -scheme Passgen -configuration Debug build` で確認する。

## 完了条件

- tips だけで、結果行の `総合`、`bits`、`長さ`、`耐性`、`広さ`、`既知`、`推測` の意味が分かる。
- 100 文字省略表示の注記が、生成結果一覧の上部に 1 回だけ表示される。
- 文字数が十分長く、暗号学的にランダムな生成結果では、偶発的な短いパターンだけで `既知リスク` や `推測されにくさ` が低評価にならない。
- 短いパスワードや、全体の大部分が単純パターンのパスワードは引き続き高評価にならない。
