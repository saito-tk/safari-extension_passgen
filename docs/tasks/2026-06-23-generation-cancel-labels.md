# 生成停止ボタン文言の調整

## 背景

生成中止の状態表示として `中止` / `中止処理中` を使っていたが、ボタン文言としては内部処理寄りで硬い。生成を途中で止める操作として、より短く自然な `停止` / `停止中...` に変更する。

## タスク

- [x] `docs/design/generation-cancel.md` のボタン文言仕様を更新する。
- [x] `README.md` と `AGENTS.md` の生成中止説明を更新する。
- [ ] 生成ボタンの表示文言を `停止` / `停止中...` に変更する。
- [ ] Xcode build で確認する。

## 確認観点

- 生成中はボタンが `停止` と表示される。
- `停止` を押すとすぐ `停止中...` に変わり、ボタンが押せなくなる。
- 停止完了後は `生成` に戻る。
