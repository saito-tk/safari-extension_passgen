# プリセット行への文字数表示

## 背景

プリセット一覧の各行には `条件 n字/m種` を表示しているが、これは使える文字セット数であり、保存されたパスワードの文字数ではない。プリセットを選ぶときは文字数も分かると便利だが、生成件数はプリセット一覧の識別情報としては優先度が低い。

## 確認観点

- プリセット行に `文字数 16 / 条件 94字/4種` のような要約が表示される。
- プリセット行に生成件数は表示されない。
- プリセットを選択したときの設定反映は従来どおり動作する。
