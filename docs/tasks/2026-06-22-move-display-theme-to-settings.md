# 表示テーマを設定画面へ移動する

## 背景

中央カラムの `表示テーマ` は見た目だけに影響する設定であり、生成条件の設定群と同じ場所にあると中央カラムの密度が上がる。アプリ全体の外観を切り替える `アプリテーマ` と近い意味を持つため、設定画面に集約する。

## タスク

- [x] Xcode build で確認する。

## 受け入れ条件

- 中央カラムに `表示テーマ` セクションが表示されない。
- 設定画面の `アプリテーマ` の下に `表示テーマ` が表示される。
- 設定画面のスウォッチから表示テーマを変更できる。
- 表示テーマ変更後も生成ロジックには影響しない。
