# コピー完了フィードバックのボタン下表示

## 背景

`コピーしました` の一時フィードバックは、コピーアイコンの左側よりもボタンの真下に表示した方が、コピー操作に対する反応として自然に見える。結果行の高さは変えず、コピーアイコン周辺のオーバーレイとして表示する。

## タスク

- [x] `docs/design/result-copy-feedback.md` の一時フィードバック位置をボタン真下へ更新する。
- [x] `コピーしました` をコピーアイコンの真下に表示する。
- [x] 一時フィードバック表示で結果行の高さが変わらない状態を維持する。
- [x] Xcode build で確認する。

## 確認観点

- `コピーしました` がコピーアイコンの真下に表示される。
- 長いパスワード行でも、コピーボタン自体は行の上下中央に配置される。
- `コピーしました` の表示/非表示で結果行の高さが変わらない。
