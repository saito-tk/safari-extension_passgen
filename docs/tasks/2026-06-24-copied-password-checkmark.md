# コピー済みパスワードのチェックマーク表示

## 背景

現在はコピー直後に `Copied!` を一時表示しているが、どのパスワードを一度コピーしたかは時間が経つと分からなくなる。生成結果一覧に残っている間は、コピー済み行のコピーアイコンにチェックマークを付けて、再コピー可能なまま視覚的な目印を残す。

## タスク

- [x] `docs/design/result-copy-feedback.md` にコピー済み表示仕様を追加する。
- [x] `README.md` のコピー表示説明を更新する。
- [x] コピー後、該当行のコピーアイコンにチェックマークを表示する。
- [x] チェックマーク表示後も同じボタンから再度コピーできる状態を維持する。
- [x] `Copied!` の一時文言表示を廃止する。
- [x] Xcode build で確認する。

## 確認観点

- コピーした行のコピーアイコンにチェックマークが付く。
- チェックマークが付いた行でも、再度コピーできる。
- コピーしていない行にはチェックマークが付かない。
- 新しく生成した結果行では、過去のコピー済み表示が残らない。
