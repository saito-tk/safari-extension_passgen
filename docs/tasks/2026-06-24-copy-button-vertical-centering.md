# コピーボタンの上下中央配置

## 背景

200 文字など長いパスワードを生成すると、結果行のパスワード表示が複数行になり、行の高さが大きくなる。その状態でも右側のコピーボタンが上寄せに見えないよう、結果行全体の上下中央に配置したい。

## タスク

- [x] `docs/design/result-copy-feedback.md` にコピーボタンの上下中央配置仕様を追記する。
- [x] 長いパスワードで結果行が高くなっても、コピーボタンが上下中央に配置されるようにする。
- [x] コピー済みチェックマークとコピー直後フィードバックの挙動を維持する。
- [x] Xcode build で確認する。

## 確認観点

- 短いパスワード行でもコピーボタンの見た目が崩れない。
- 長いパスワード行でもコピーボタンが上寄せにならず、行の上下中央に見える。
- コピー後のチェックマークと `コピーしました` の一時表示は従来どおり動作する。
