# 全角数字を入力確定後すぐ半角へ変換する

## 背景

文字数と件数の入力欄では全角数字を半角数字へ変換しているが、TextField の Binding 側だけで変換すると、IME 確定直後の表示更新が環境によって分かりにくい可能性がある。入力値そのものを ViewModel 側でも正規化し、入力確定後すぐ半角表示になることを保証する。

- [x] 正規化時に補正警告の表示制御が壊れないことを確認する。
- [x] Xcode build で確認する。

## 受け入れ条件

- `１２３` を入力して確定した直後、入力欄の表示が `123` になる。
- 全角数字から半角数字への変換だけでは警告メッセージを出さない。
- 範囲外補正は従来どおりフォーカスアウト時に行われる。
