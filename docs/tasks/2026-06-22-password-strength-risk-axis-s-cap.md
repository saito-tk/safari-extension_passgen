# パスワード強度リスク軸の S 評価抑制タスク

## 背景

`既知リスク` と `推測されにくさ` は、長いランダム生成結果の偶発一致を過度に減点しないよう補正した。一方で、危険シグナルが検出されないだけで短い生成結果にも `S` が出やすくなると、個別軸の表示として過大評価に見える。

`既知リスク` と `推測されにくさ` は危険シグナルの検出軸だが、表示上は S-F の評価として読まれるため、短いパスワードでは `S` まで上げない。

## タスク

- [x] `docs/design/password-strength-analysis.md` に、危険シグナル未検出だけでは `S` にしない方針を追記する。
- [x] `既知リスク` と `推測されにくさ` に、長さと推定 entropy による上限を適用する。

## 完了条件

- 4-7 文字程度の短い生成結果で、危険シグナルが検出されなくても `既知` と `推測` が `S` にならない。
- 8-14 文字程度の生成結果で、危険シグナルが検出されなくても `既知` と `推測` は最大 `B` に抑えられる。
- 15 文字以上かつ一定の推定 entropy がある生成結果は、危険シグナルがなければ最大 `A` まで上がる。
- 20 文字以上かつ十分な推定 entropy がある生成結果は、危険シグナルがなければ `S` を取れる。
- blocklist 全体一致、単純派生、全体を占める単純パターンは引き続き低評価になる。
