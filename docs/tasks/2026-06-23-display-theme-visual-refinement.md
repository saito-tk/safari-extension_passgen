# 表示テーマの選択状態と青緑配色の再調整

## 背景

テーマ追加後、設定画面の選択中スウォッチが非活性状態のように見え、青と緑のダークモード配色が他テーマより浮いて見える。選択中であることを明確にし、青と緑も他テーマと同じ落ち着いたバランスに揃える。

## タスク

- [x] `docs/design/app-settings.md` に選択中表示と青緑の配色方針を追記する。
- [x] 表示テーマスウォッチの選択中表示を非活性に見えない見た目へ変更する。
- [x] 青と緑のダークモード配色を他テーマと同じ低彩度バランスへ調整する。
- [x] Xcode build で確認する。

## 確認観点

- 選択中スウォッチが disabled ではなく selected として見える。
- 青と緑を選んでも、他のテーマより明るく浮いて見えない。
- 既存テーマ切り替え動作と保存復元は維持される。
