# ロック中プリセットの文字数/件数編集 実装タスク

## 背景

プリセットロックは保存済み内容を誤って更新しないための保護だが、文字数と件数は今回の生成に合わせて一時的に調整したいケースがある。ロック中でも文字数と件数は変更できるようにし、保存/更新だけは引き続き止める。

## タスク

- [x] `docs/design/preset-saving.md` に、ロック中でも文字数と件数を変更できる仕様を追加する。
- [x] `README.md` と tips 仕様のロック説明を更新する。
- [ ] ロック中プリセット選択中でも `文字数` 入力欄を編集可能にする。
- [ ] ロック中プリセット選択中でも `件数` 入力欄を編集可能にする。
- [ ] ロック中に文字数や件数を変更しても、保存ボタンは `ロック中` 表示で無効のままにする。
- [ ] Xcode build で確認する。

## 確認観点

- ロック中プリセットを選択している間、文字数と件数を変更できる。
- ロック中プリセットを選択している間、文字選択や生成ルールは変更できない。
- 文字数や件数の変更後もプリセットは更新されず、保存ボタンは `ロック中` のままになる。
