# プリセットロック 実装タスク

## 背景

保存済みプリセットは選択後に設定を変更して `更新` できるが、よく使うプリセットを誤って変更したくないケースがある。プリセット一覧の設定メニューにロック機能を追加し、ロック中は選択や削除は維持しながら、生成設定の編集と更新を止める。

## タスク

- [x] `docs/design/preset-saving.md` にロック仕様を追加する。
- [x] `README.md` と tips 仕様にロックの説明を追加する。
- [ ] プリセットデータにロック状態を保存し、既存データは未ロックとして復元する。
- [ ] プリセット行の設定メニューからロック/ロック解除を切り替えられるようにする。
- [ ] ロック中プリセットの行に鍵アイコンを表示する。
- [ ] ロック中プリセット選択中は、中央カラムのパスワード設定 UI を編集不可にする。
- [ ] ロック中プリセット選択中は、保存ボタンを `ロック中` 表示にして常に無効化する。
- [ ] 未選択時の同名保存でロック中プリセットを上書きしない。
- [ ] Xcode build で確認する。

## 確認観点

- ロック中プリセットも一覧から選択/選択解除できる。
- ロック中プリセットを選択している間は、文字数、件数、文字選択、生成ルール、先頭文字、除外文字を変更できない。
- ロック中プリセットを選択している間は、更新ボタンが `ロック中` 表示で無効になる。
- ロック解除すると、通常どおり設定変更と更新ができる。
- ロック中プリセットと同名で保存しようとしても上書きされない。
- 既存の保存済みプリセットは未ロックとして読み込まれる。
