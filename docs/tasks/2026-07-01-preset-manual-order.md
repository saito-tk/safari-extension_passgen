# プリセット手動並び替え 実装タスク

## 背景

保存済みプリセットは名前、作成日、更新日で並び替えられるが、よく使う順や用途別の並びにしたい場合がある。普段のプリセット選択操作を邪魔しないよう、手動並び替えは明示的に選んだ時だけ操作できるようにする。

## 対応

- [x] `docs/design/preset-saving.md` に手動並び替え仕様を追加する。
- [x] 並び順メニューに `手動` を追加する。
- [x] `手動` 選択中だけプリセット行をドラッグできるようにする。
- [x] ドラッグ中は挿入予定位置だけ表示し、ドロップ時に並び替える。
- [x] `手動` 選択中も昇順/降順を切り替えられるようにする。
- [x] 手動順は既存のプリセット配列順として保持し、保存済みプリセット永続化に反映する。
- [x] 名前、作成日、更新日の自動ソート中はドラッグ並び替えを使わない。

## 現在の扱い

- 実装は残す。
- UI がまだ微妙なため、通常 UI では `手動` を表示せず、ドラッグ並び替えも無効化しておく。
