# コピー完了フィードバックのボタン表現化

## 背景

`コピーしました` のテキスト表示をボタン下に収めるために固定領域を確保した結果、結果行の高さやコピーボタンの上下中央配置に悪影響が出た。コピー完了は伝えたいが、テキストバッジでレイアウトを動かすのは避ける。

## タスク

- [x] `docs/design/result-copy-feedback.md` を、テキスト表示ではなくボタン自体の短時間フィードバック仕様へ更新する。
- [ ] `コピーしました` テキスト表示と固定フィードバック領域を削除する。
- [ ] コピー直後はコピーアイコンボタンの見た目だけで完了状態を示す。
- [ ] コピーボタンを結果行の上下中央に戻す。
- [ ] Xcode build で確認する。

## 確認観点

- コピー直後にボタン自体の色や枠線が短時間変わる。
- `コピーしました` テキストは表示されない。
- 短い結果行でも長い結果行でも、コピーボタンは行の上下中央に見える。
- コピー済みチェックマークは引き続き残る。
