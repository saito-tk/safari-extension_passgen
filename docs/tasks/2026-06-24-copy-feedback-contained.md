# コピー完了フィードバックの枠内表示

## 背景

`コピーしました` をコピーアイコンの真下へオーバーレイ表示したところ、短い結果行ではカード枠外へはみ出す。コピー完了表示はボタンの近くに置きたいが、結果行の外へ出ると UI として不自然に見える。

## タスク

- [x] `docs/design/result-copy-feedback.md` に、コピー完了フィードバックを枠内へ収める仕様を追記する。
- [x] コピーコントロール内に固定のフィードバック領域を確保する。
- [x] `コピーしました` をコピーアイコンの真下かつ結果行の枠内に表示する。
- [x] フィードバック表示/非表示で結果行の高さが変わらない状態を維持する。
- [x] Xcode build で確認する。

## 確認観点

- `コピーしました` が結果行の枠外にはみ出さない。
- `コピーしました` が省略されずに表示される。
- `コピーしました` の表示/非表示で結果行の高さが変わらない。
