# 生成結果識別子のハッシュ表記

## 背景

生成結果一覧に `生成ID` と表示すると、外部サービスや履歴管理と照合できる ID のように見える可能性がある。用途は生成結果セットとテキスト出力ファイル名を対応させるための短い目印なので、表示名は `ハッシュ` にする。

また、`ハッシュ` と表示する以上、UUID の先頭文字列をそのまま使うのではなく、内部 UUID から SHA-256 の短縮値を作って表示する。

- 生成結果本文にはハッシュや日時などのメタ情報が含まれない。
