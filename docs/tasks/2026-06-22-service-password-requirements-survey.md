# メジャーサービスのパスワード条件調査

作成日: 2026-06-22

## 背景

ユーザーから、実装前に国内で利用されるメジャーサービスのパスワード設定条件を調べ、文字数上限、数字、記号、文字種制限をドキュメント化したいという依頼があった。

## 対応内容

- [x] 国内利用が多いサービスを 30 件以上洗い出す。
- [x] 公式情報を優先し、文字数、文字種、記号、出典、確度を整理する。
- [x] 完全な条件が公開されていないサービスは、推測で埋めずに未公開として扱う。
- [x] Passgen のプリセット設計に使える示唆をまとめる。
- [x] Chrome で公開登録画面の追加確認を行い、確認できた範囲と制約を追記する。
- [x] 実装は行わない。

## 成果物

- `docs/design/service-password-requirements-survey.md`

## 検証

- [x] ドキュメントのみの追加であることを確認する。
- [x] Chrome で公開登録画面の追加確認を行い、確認できた範囲と制約を記録する。
