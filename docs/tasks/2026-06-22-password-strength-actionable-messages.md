# パスワード強度メッセージ改善タスク

## 背景

現在の強度補助メッセージは、15文字以上などで目立つリスクが検出されない場合に `目立つ既知リスクや推測パターンは検出されていません。総合評価も確認してください。` と表示される。これは評価理由として弱く、総合評価への参照を促すだけで実質的な情報量が少ない。

強度メッセージは、問題や改善余地があるときだけ表示し、ユーザーが次にどの設定を変えればよいか分かる内容にする。

## タスク

- [ ] 強度評価仕様に、補助メッセージは問題・注意・改善余地がある場合だけ表示する方針を追記する。
- [ ] 警告がない場合の汎用肯定メッセージを廃止する。
- [ ] `B` / `C` 相当の長さや総当たり耐性に、具体的な改善提案メッセージを追加する。
- [ ] メッセージがない場合は、結果行に空行を表示しない。
- [ ] Xcode build で確認する。

## 完了条件

- 目立つリスクがない `S` / `A` 評価では、不要な補助メッセージが表示されない。
- 15文字程度や 80-99 bits 程度の結果では、改善余地が分かる補助メッセージが表示される。
- `総合評価も確認してください` のような参照誘導だけの文言が表示されない。
