# コピー完了フィードバックの文字幅修正

## 背景

`コピーしました` をコピーアイコンの真下へ移動した結果、ボタン幅の影響でオーバーレイが丸くなり、文言が省略される。コピー完了を伝える表示なので、文言は 1 行で読める必要がある。

## タスク

- [x] `docs/design/result-copy-feedback.md` に一時フィードバック文言を省略しない仕様を追記する。
- [ ] `コピーしました` が丸く潰れず、1 行で読めるようにする。
- [ ] 一時フィードバック表示で結果行の高さが変わらない状態を維持する。
- [ ] Xcode build で確認する。

## 確認観点

- `コピーしました` が省略されずに表示される。
- バッジが丸い点のようにならない。
- `コピーしました` の表示/非表示で結果行の高さが変わらない。
