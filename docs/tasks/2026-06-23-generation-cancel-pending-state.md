# 生成中止処理中状態の追加

作成日: 2026-06-23

## 背景

999,999 文字など、1 件の生成自体に時間がかかる条件では、`中止` を押しても次のキャンセル確認まで待ち時間が発生する。現状ではその間も `中止` ボタンが押せるように見えるため、ユーザーには中止要求が受理されたか分かりづらい。

## 対応内容

- [x] `docs/design/generation-cancel.md` に中止処理中状態を追記する。
- [x] `README.md` と `AGENTS.md` の生成中仕様を更新する。
- [x] `中止` 押下直後に `中止処理中` 表示へ切り替える。
- [x] 中止処理中は生成ボタンを非活性にする。
- [x] キャンセル完了、生成完了、生成エラー時に中止処理中状態を解除する。
- [x] Xcode build で確認する。

## 検証観点

- 生成中はボタンが `中止` と表示される。
- `中止` を押すとすぐ `中止処理中` に変わり、ボタンが押せなくなる。
- キャンセル完了後は `生成` に戻る。
- 中止前に生成済みの結果は残る。
