# 左カラム tips 追加と数値補正警告の復旧

作成日: 2026-06-23

## 背景

左カラムの保存済み設定にも、ユーザー目線で何ができるかを説明する tips が必要になった。

また、文字数/件数に範囲外の値を入力した場合の補正警告が表示されなくなっている可能性がある。現行実装では、範囲外補正後に `lengthText` / `countText` へ補正値を書き戻した際、その `didSet` が警告を入力変更として即時クリアしている可能性が高い。

## 対応内容

- [x] `docs/design/section-help-tips.md` に左カラム tips の仕様を追加する。
- [x] `docs/design/numeric-inputs.md` に、補正値の内部書き戻しでは警告を消さない仕様を追記する。
- [ ] 左カラム `保存済み設定` 見出しに `?` tips を追加する。
- [ ] 保存/更新、一覧、選択解除、ソート、削除、テーマ非保存を説明する tips を実装する。
- [ ] 範囲外補正警告が補正直後に消えないように修正する。
- [ ] Xcode build で確認する。

## 検証観点

- 左カラムの `?` から保存済み設定の説明が表示される。
- 文字数に `1` など範囲外の値を入力してフォーカスアウトすると、補正値と警告が表示される。
- 件数に範囲外の値を入力してフォーカスアウトすると、補正値と警告が表示される。
- 警告表示後、文字数/件数を再編集すると警告が消える。
- 生成ボタン押下時は従来どおり直前の補正警告が消える。
