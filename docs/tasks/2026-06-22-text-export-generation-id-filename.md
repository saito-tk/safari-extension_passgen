# テキスト出力ファイル名へのハッシュ反映タスク

## 背景

生成結果をテキスト出力したあと、どの生成結果セット由来のファイルかを識別しやすくしたい。フル UUID をファイル名に含めると長くなりすぎるため、内部ではフル UUID を保持し、ファイル名には短縮ハッシュを使う。

## タスク

- [x] `docs/design/text-export.md` に生成ハッシュとデフォルトファイル名仕様を追加する。
- [x] 生成開始時に生成結果セット用 UUID と生成開始時刻を保持する。
- [x] テキスト出力のデフォルトファイル名を `passgen-yyMMddHHmm-shortid.txt` にする。
- [x] README のテキスト出力説明を更新する。
- [x] Xcode build で確認する。

## 完了条件

- 生成ボタン押下ごとに新しい生成結果セット用 UUID から短縮ハッシュが作られる。
- 同じ生成結果セットを複数回出力する場合、同じ短縮ハッシュのファイル名が提示される。
- 生成し直すと、デフォルトファイル名の短縮ハッシュが変わる。
- テキスト本文は 1 パスワード 1 行のままで、ハッシュや日時を含まない。
