# 数値入力の範囲表示と全角数字変換

## 背景

文字数と件数は入力可能な範囲が決まっているが、入力欄の近くに常時表示されていないため、入力後の補正メッセージを見るまで範囲が分かりにくい。また、日本語入力環境では全角数字が入りやすいため、数値として自然に扱えるようにしたい。

## タスク

- [x] 数値入力仕様に、入力範囲表示と全角数字変換の方針を追加する。
- [x] README に、範囲表示と全角数字変換を追記する。
- [ ] `文字数` 入力カード内に入力範囲を小さく表示する。
- [ ] `件数` 入力カード内に現在の文字数に応じた入力範囲を小さく表示する。
- [ ] `文字数` と `件数` の入力中に全角数字を半角数字へ変換する。
- [ ] Xcode build で確認する。

## 受け入れ条件

- `文字数` 入力カード内で `4〜999,999` のような範囲が確認できる。
- `件数` 入力カード内で現在の文字数に応じた件数範囲が確認できる。
- `１２３` を入力すると、入力欄の表示が `123` になる。
- 範囲外補正は従来どおりフォーカスアウト時に行われる。
