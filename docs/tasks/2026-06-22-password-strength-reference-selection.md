# パスワード強度評価の参考情報選定タスク

## 対応仕様

- `docs/design/password-strength-analysis.md`

## 目的

パスワード強度評価に使う外部参考情報を、生成アプリとして必要な範囲に絞って仕様へ反映する。

## 作業タスク

- [x] NIST と OWASP を主軸として採用する理由を明記する。
- [x] NCSC、zxcvbn、RFC 4086 を補助参考として採用する範囲を明記する。
- [x] Have I Been Pwned のオンライン照合や全漏洩コーパス同梱を標準採用しない理由を明記する。
- [x] 組織運用向け資料や機械学習型メーターを現時点で採用しない理由を明記する。
- [x] `既知リスク` を、漏洩安全性の保証ではなく軽量 blocklist とパターン検出による推定リスクとして定義する。

## 完了条件

- 参考情報を「とりあえず使う」のではなく、採用範囲と非採用範囲が仕様上で区別されている。
- 生成アプリとして標準機能に含めるべき評価と、将来の任意機能に留める評価が区別されている。
