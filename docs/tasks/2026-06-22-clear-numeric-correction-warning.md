# 数値入力の補正警告を一時表示にする

## 背景

文字数や件数に範囲外の値を入力した場合、フォーカスアウト時に補正警告が表示される。しかし一度表示されると、生成操作や入力変更後も残り続けるため、現在の状態に対する警告なのか過去の案内なのか分かりにくい。

## タスク

- [x] 数値入力仕様に、補正警告を一時表示として扱う方針を追加する。
- [x] README に、補正警告が生成時や入力変更時に消えることを追記する。
- [ ] `生成` ボタン押下時に、直前の補正警告を非表示にする。
- [ ] 文字数または件数の入力内容が変更されたら、直前の補正警告を非表示にする。
- [ ] Xcode build で確認する。

## 受け入れ条件

- 範囲外補正後に表示された警告が、`生成` ボタン押下後に残り続けない。
- 範囲外補正後に表示された警告が、文字数または件数の入力変更後に残り続けない。
- 生成不可などのエラーメッセージは、補正警告の非表示処理で意図せず消さない。
