# プリセット一覧ソートと選択解除 実装タスク

## 対応仕様

- `docs/design/preset-saving.md`

## 目的

プリセット一覧を名前/作成日/更新日でソートできるようにし、表示内容をソート条件に合わせて整理する。あわせて、プリセット選択中の更新保存と、再選択による選択解除・選択前設定への復元を実装する。

## 作業タスク

- [ ] プリセット一覧のソート条件とソート方向を ViewModel に追加する。
- [ ] 名前/作成日/更新日のソート UI を左カラムに追加する。
- [ ] 一覧行は通常は名前だけを表示し、作成日ソート時は作成日、更新日ソート時は更新日を追加表示する。
- [ ] 選択中プリセットを再度選択したときに選択解除できるようにする。
- [ ] プリセット選択前の現在設定を保持し、選択解除時に復元する。
- [ ] プリセット選択中の保存では、選択中プリセットを更新する。
- [ ] 選択中プリセット更新時は、入力欄の名前でプリセット名も更新する。
- [ ] README または TODO に必要な進捗更新を反映する。
- [ ] `xcodebuild -project xcode/Passgen/Passgen.xcodeproj -scheme Passgen -configuration Debug build` で確認する。

## 完了条件

- 名前ソート時は一覧行にプリセット名だけが表示される。
- 作成日ソート時は名前と作成日が表示される。
- 更新日ソート時は名前と更新日が表示される。
- 選択中プリセットを再度選択すると選択解除され、選択前の設定へ戻る。
- プリセット選択中に保存すると、そのプリセットが更新される。
