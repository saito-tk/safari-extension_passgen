# プリセット行クリック範囲の再修正

## 背景

プリセット一覧は、設定ボタンを除く行全域を選択/選択解除のクリック対象にする仕様である。しかし現状では、プリセット名などのラベル領域をクリックした場合だけ反応し、枠内の余白部分では選択されない。

## タスク

- [x] 既存仕様 `docs/design/preset-saving.md` が行全域クリックを定義していることを確認する。
- [ ] プリセット行の選択ボタンが枠内の余白までヒット領域を持つように修正する。
- [ ] 設定ボタンは従来どおり削除メニュー専用のクリック対象として残す。
- [ ] Xcode build で確認する。

## 確認観点

- プリセット行の名前、条件、日付、余白部分をクリックして選択/選択解除できる。
- 行右側の設定ボタンをクリックしてもプリセット選択は発火しない。
- 生成中は従来どおりプリセット選択と設定ボタンが無効になる。
