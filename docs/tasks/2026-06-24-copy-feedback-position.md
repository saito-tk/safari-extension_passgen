# コピー完了フィードバック位置調整

## 背景

`コピーしました` の一時フィードバックを結果行の右上に表示すると、長いパスワードで行が高くなったときに、コピーアイコンとの関係が分かりにくい。コピー操作への反応として自然に見えるよう、コピーアイコンの左側に同じ上下位置で表示する。

## タスク

- [x] `docs/design/result-copy-feedback.md` に一時フィードバックの表示位置を追記する。
- [x] `コピーしました` をコピーアイコンの左側に表示する。
- [x] 一時フィードバック表示で結果行の高さが変わらない状態を維持する。
- [x] Xcode build で確認する。

## 確認観点

- `コピーしました` がコピーアイコンの近くに表示され、操作対象との関係が分かる。
- 長いパスワード行でも、表示位置が上端に寄らない。
- `コピーしました` の表示/非表示で結果行の高さが変わらない。
