# 強度評価 tips と総当たり耐性ラベルを見直す

## 背景

生成結果行の `耐性` は短縮しすぎており、表示領域にも余裕があるため `総当たり耐性` と表示した方が意味が伝わりやすい。強度評価 tips も、技術用語の説明に寄りすぎると、専門知識がないユーザーには評価の読み方が分かりにくい。

## タスク

- [x] 強度評価仕様に、結果行では `耐性` ではなく `総当たり耐性` と表示する方針を追記する。
- [x] 強度評価仕様に、tips は専門知識がないユーザーでも分かる表現にする方針を追記する。
- [x] README の `総当たり耐性` と `推定エントロピー` の説明を平易にする。
- [ ] パスワードごとの評価バッジを `耐性` から `総当たり耐性` へ変更する。
- [ ] 強度評価 tips の全体文言を、画面の読み方・グレード・警告の意味が自然に追える内容へ更新する。
- [ ] 修正後の tips を読み直し、技術的知識がない人にも分かる表現か確認する。
- [ ] Xcode build で確認する。

## 受け入れ条件

- 結果行のバッジに `総当たり耐性` と表示される。
- tips 内で `耐性` という短縮ラベルを前提にした説明が残らない。
- tips を読めば、`総合`、`長さ`、`総当たり耐性`、`推定エントロピー`、`条件`、警告メッセージの意味が分かる。
- tips の説明が、専門用語だけで終わらず、技術的知識がない人にも意味を想像できる表現になっている。
