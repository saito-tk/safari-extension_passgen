# 生成結果保護設定と表示安定化 実装タスク

## 目的

生成結果の初期マスク、コピー後の自動削除、プリセット操作、スクロール終端表示を整理し、件数が多い場合も結果ヘッダを安定させる。

## タスク

- [x] 設定画面にコピー後の自動削除の有無と秒数を追加する。
- [x] 設定画面に生成後のパスワードを隠す初期設定を追加する。
- [x] 初期状態で生成結果をマスク表示にする。
- [x] ロック中のプリセットのメニューから削除項目を隠す。
- [x] 結果ヘッダが件数に応じて不安定に改行しないようにする。
- [x] プリセット一覧と中央カラムの下端フェードを取り除く。
- [x] Xcode build で確認する。
