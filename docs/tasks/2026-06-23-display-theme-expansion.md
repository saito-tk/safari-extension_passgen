# 表示テーマ追加とダークモード配色調整

## 背景

現在の表示テーマは 7 色で選択肢が少なく、青以外をダークモードで選ぶとアクセント色や背景色が強く感じられる。テーマ数を増やしつつ、ダークモードでは長時間見ても疲れにくい低彩度寄りの配色に調整する。

## タスク

- [x] `docs/design/app-settings.md` にテーマ一覧と配色方針を追記する。
- [x] `README.md` と `AGENTS.md` のテーマ一覧を更新する。
- [x] `NativeTheme` に追加テーマを定義する。
- [x] 既存テーマを含め、ダークモードの配色を低彩度寄りに調整する。
- [x] 設定画面の表示テーマスウォッチを複数行表示に変更する。
- [x] Xcode build で確認する。

## 確認観点

- 設定画面に 13 テーマが表示される。
- 表示テーマを切り替えると生成画面へ反映される。
- ダークモードで青以外を選んでも、背景やアクセントが強く光りすぎない。
- 既存の保存済みテーマ値は引き続き復元できる。
