# 文字選択エディタと生成ルールに tips を追加する

## 背景

現在、画面内の `?` tips は生成結果の強度評価にだけある。文字選択エディタや生成ルールは、初見のユーザーには「何を変える場所なのか」「どの設定が生成結果にどう影響するのか」が分かりにくい。

## タスク

- [x] 画面内 tips の設計を追加する。
- [x] README に、画面内 tips を確認できることを追記する。
- [ ] `文字選択エディタ` 見出しに `?` tips を追加する。
- [ ] `生成ルール` 見出しに `?` tips を追加する。
- [ ] tips の説明をユーザー目線で分かりやすい表現にする。
- [ ] Xcode build で確認する。

## 受け入れ条件

- `文字選択エディタ` の `?` から、文字選択や現在選択中の文字の意味が分かる。
- `生成ルール` の `?` から、生成方式、似た文字除外、必須文字種、連続文字、先頭文字設定の意味が分かる。
- tips の説明が、技術的知識がない人にも意味を追える表現になっている。
- 既存の強度評価 tips が壊れない。
