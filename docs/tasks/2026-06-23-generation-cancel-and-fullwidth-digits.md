# 生成中止と全角数字入力の維持

作成日: 2026-06-23

## 背景

長いパスワードや大量件数を生成している途中で、ユーザーが生成を中止できるようにしたい。

また、文字数/件数入力欄では、全角数字も入力でき、IME の入力確定後すぐ半角数字へ変換される挙動を維持する。

## 対応内容

- [x] `docs/design/generation-cancel.md` に生成中止仕様を追加する。
- [x] `README.md` と `AGENTS.md` の生成中仕様を更新する。
- [x] 生成中も生成ボタンを押せるようにし、表示を `中止` に変える。
- [x] `中止` 押下時に現在の生成タスクをキャンセルする。
- [x] 中止前に生成済みの結果を一覧に残す。
- [x] 中止後にユーザー操作による中断メッセージを表示する。
- [x] 文字数/件数の全角数字が入力確定後すぐ半角数字へ変換される挙動を維持する。
- [x] Xcode build で確認する。

## 検証観点

- 生成中にボタン表示が `中止` になる。
- `中止` を押すと生成が止まり、設定系 UI が再び操作可能になる。
- 中止前に生成済みの結果が残る。
- 中止後に `生成を中止しました。` が表示される。
- 生成中以外は従来どおり `生成` ボタンで生成を開始できる。
- 文字数/件数へ全角数字を入力して確定すると、入力欄内で半角数字に変換される。
