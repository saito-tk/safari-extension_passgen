# パスワードジェネレータ

macOS 向けのパスワードジェネレータアプリです。条件を指定し、複数件のパスワードをまとめて生成できます。

## 主な機能

- 暗号学的に安全な乱数を使ったパスワード生成
- 英字(大文字) / 英字(小文字) / 数字 / 記号の個別選択
- 記号の個別選択
- 記号文字列の貼り付けから記号選択状態へ反映
- 似た文字の除外
- 同一文字の連続禁止
- 生成件数の逐次表示と進捗表示
- 長いパスワードの省略表示
  - 一覧では先頭 100 文字まで表示
  - 実際の文字数は注記で案内
- 行ごとのコピーアイコン
- 生成結果のテキスト出力
- 名前付きプリセット保存と呼び出し
- 文字選択エディタ、生成ルール、強度評価の画面内 tips
- 設定画面でのアプリ外観と表示テーマ切り替え
  - 青 / 緑 / ティール / ミント / シアン / インディゴ / 紫 / ラベンダー / ピンク / ローズ / オレンジ / 黄色 / グレー
- アプリ内設定の保存

## UI 構成

- 左カラム
  - 保存済み設定一覧
  - 現在設定のプリセット保存
- 中央カラム
  - 文字数 / 件数
  - 文字種の選択
  - 記号の選択
  - 生成ルールの設定
- 右カラム
  - 生成されたパスワード一覧
  - 進捗表示 `(n/件数)`
  - コピー操作
  - テキスト出力
  - 強度や補助情報

## 入力仕様

- 文字数
  - 最小 `4`
  - 最大 `999,999`
- 件数
  - 最小 `1`
  - 最大 `1,000`
  - ただし文字数に応じて上限が下がります
  - 実際の上限は `min(1000, floor(9999990 / 文字数))`
  - 例: 文字数 `999,999` の場合、生成件数は最大 `10`

数値入力は編集中には補正せず、フォーカスが外れた時点で範囲内へ補正されます。
文字数と件数の入力欄には、現在設定できる範囲を小さく表示します。
全角数字を入力した場合は、入力確定後すぐ入力欄内で半角数字へ変換されます。
範囲外補正の警告は一時的な案内として表示し、`生成` ボタンを押した時や文字数・件数を変更した時に非表示になります。

## 記号貼り付け機能

記号欄の下にある入力欄へ文字列を貼り付けて `反映` を押すと、対応する記号だけが選択状態になります。

この機能は、サービスごとに「使用できる記号」が異なるケースを想定しています。サービス側が利用可能な記号一覧を表示している場合、その文字列をコピーしてすぐにアプリ側へ反映できるため、記号設定を手で 1 つずつ合わせる手間を減らせます。

- 対応する記号が含まれている場合
  - 含まれる記号を選択
  - 含まれない記号を非選択
- 対応外の文字しか含まれていない場合
  - 記号選択状態は変更しない
- 反映後
  - 入力欄は空になる
  - `反映` ボタンは非活性になる

## 生成中の挙動

- `生成` ボタンを押した時だけ生成を開始します
- 生成中の `生成` ボタンは `停止` に変わり、押すと生成を止められます
- 停止を押した後、停止が完了するまでは `停止中...` と表示され、ボタンは押せなくなります
- 生成中は設定系 UI を非活性にします
- 結果は 1 件ずつ追加表示されます
- 停止した場合、停止前に生成済みの結果は一覧に残ります

## コピー表示

- 各結果行の右側にコピーアイコンがあります
- コピーアイコンをクリックすると、その行のパスワードがクリップボードにコピーされます

## 強度表示

生成結果には、強度の目安として `総合評価` が表示されます。総合評価は `S` / `A` / `B` / `C` / `D` / `F` の 6 段階です。

評価は以下の観点で行います。

- `長さ`: 文字数そのものの評価。15 文字以上を重視し、24 文字以上を `S` とします。
- `総当たり耐性`: すべての候補を順番に試されたときの破られにくさ。固定文字を除いたランダム生成部分から見積もります。
- `文字の広さ`: 生成に使える文字セット数とカテゴリ数。生成結果一覧の上側とプリセット一覧の `条件` に表示します。プリセット一覧では保存された `文字数` と `条件` を分けて表示しますが、件数は表示しません。
- `既知リスク`: ローカルの軽量 blocklist との全体一致や、弱い候補の単純変形の検出。問題がある場合だけ警告します。
- `推測されやすいパターン`: 連番、キーボード配列、日付、繰り返しなどの検出。問題がある場合だけ警告します。

総合評価は `長さ` と `総当たり耐性` を主軸に決めます。`既知リスク` と `推測されやすいパターン` は、良い状態を加点する評価ではなく、問題がある場合だけ総合評価の上限を下げる警告として扱います。

`既知リスク` はオンライン漏洩データベース照合ではありません。生成結果を外部へ送らず、アプリ内の軽量 blocklist とパターン検出による目安として表示します。検出がない場合でも、漏洩済みではないことを保証するものではありません。

長いランダム生成結果では、短い一般語や連番が偶然含まれることがあります。そのため、短い部分一致だけでは大きく減点せず、パスワード全体に対して意味のある割合を占める場合に評価へ反映します。

あわせて表示される `推定エントロピー: xxx bits` は、総当たり耐性を数値化したものです。同じ生成条件で作られた結果では共通の値になるため、各パスワード行には繰り返し表示しません。固定先頭文字を指定している場合、その固定文字は他人に知られている前提で推定エントロピーには含めません。

## テキスト出力

生成結果は、右カラムの `テキスト出力` から `.txt` ファイルとして保存できます。

出力形式は 1 パスワード 1 行です。

テキスト出力のデフォルトファイル名は、生成開始時刻と生成IDの短縮版を使います。

```text
passgen-2606220930-a1b2c3d4e5f6.txt
```

生成IDは `生成` ボタンを押すたびに新しく発行されます。同じ生成結果を複数回出力する場合は、同じ短縮IDがファイル名に使われます。本文には生成IDや日時は出力しません。
生成結果一覧にも短縮IDを `生成ID` として表示します。

```text
aaaaa
bbbbb
ccccc
```

2. `Passgen` スキームで `Run`
