# パスワードジェネレータ

macOS 向けのパスワードジェネレータアプリです。条件を指定し、複数件のパスワードをまとめて生成できます。

## 主な機能

- 暗号学的に安全な乱数を使ったパスワード生成
- 英字(大文字) / 英字(小文字) / 数字 / 記号の個別選択
- 記号の個別選択
- 記号文字列の貼り付けから記号選択状態へ反映
- 似た文字の除外
- 同一文字の連続禁止
- 生成件数の逐次表示と進捗表示
- 長いパスワードの省略表示
  - 一覧では先頭 100 文字まで表示
  - 実際の文字数は注記で案内
- 行ごとのコピーアイコン
- 生成結果のテキスト出力
- 名前付きプリセット保存と呼び出し
- テーマ切り替え
  - 青 / 緑 / ピンク / 赤 / 黄色 / オレンジ / 紫
- アプリ内設定の保存

## UI 構成

- 左カラム
  - 保存済み設定一覧
  - 現在設定のプリセット保存
- 中央カラム
  - 文字数 / 件数
  - 文字種の選択
  - 記号の選択
  - 生成ルールの設定
  - 表示テーマの切り替え
- 右カラム
  - 生成されたパスワード一覧
  - 進捗表示 `(n/件数)`
  - コピー操作
  - テキスト出力
  - 強度や補助情報

## 入力仕様

- 文字数
  - 最小 `4`
  - 最大 `999,999`
- 件数
  - 最小 `1`
  - 最大 `30`
  - ただし文字数に応じて上限が下がります
  - 実際の上限は `min(30, floor(999999 / 文字数))`
  - 例: 文字数 `999,999` の場合、生成件数は最大 `1`

数値入力は編集中には補正せず、フォーカスが外れた時点で範囲内へ補正されます。

## 記号貼り付け機能

記号欄の下にある入力欄へ文字列を貼り付けて `反映` を押すと、対応する記号だけが選択状態になります。

この機能は、サービスごとに「使用できる記号」が異なるケースを想定しています。サービス側が利用可能な記号一覧を表示している場合、その文字列をコピーしてすぐにアプリ側へ反映できるため、記号設定を手で 1 つずつ合わせる手間を減らせます。

- 対応する記号が含まれている場合
  - 含まれる記号を選択
  - 含まれない記号を非選択
- 対応外の文字しか含まれていない場合
  - 記号選択状態は変更しない
- 反映後
  - 入力欄は空になる
  - `反映` ボタンは非活性になる

## 生成中の挙動

- `生成` ボタンを押した時だけ生成を開始します
- 生成中は設定系 UI を非活性にします
- 結果は 1 件ずつ追加表示されます

## コピー表示

- 各結果行の右側にコピーアイコンがあります
- コピーアイコンをクリックすると、その行のパスワードがクリップボードにコピーされます

## 強度表示

生成結果には、強度の目安として `総合評価` が表示されます。総合評価は `S` / `A` / `B` / `C` / `D` / `F` の 6 段階です。

評価は以下の観点で行います。

- `長さ`: 文字数そのものの評価。15 文字以上を重視します。
- `総当たり耐性`: 文字セットサイズと文字数から見積もった推定 bits。
- `文字の広さ`: 生成に使える文字セットの広さ。文字種の混在を必須条件にはしません。
- `既知リスク`: ローカルの軽量 blocklist との全体一致や、弱い候補の単純変形の検出。
- `推測されにくさ`: 連番、キーボード配列、日付、繰り返しなどが全体に占める割合の検出。

`既知リスク` はオンライン漏洩データベース照合ではありません。生成結果を外部へ送らず、アプリ内の軽量 blocklist とパターン検出による目安として表示します。

長いランダム生成結果では、短い一般語や連番が偶然含まれることがあります。そのため、短い部分一致だけでは大きく減点せず、パスワード全体に対して意味のある割合を占める場合に評価へ反映します。

あわせて表示される `推定 xxx bits` は、使用可能な文字種の数と文字数から見積もった理論上の総当たり耐性を表します。値が大きいほど、総当たりで破られにくい傾向があります。

## テキスト出力

生成結果は、右カラムの `テキスト出力` から `.txt` ファイルとして保存できます。

出力形式は 1 パスワード 1 行です。

```text
aaaaa
bbbbb
ccccc
```

## ファイル構成

- `xcode/Passgen/Passgen/NativePasswordGeneratorView.swift`: メイン UI と生成ロジック
- `xcode/Passgen/Passgen/ViewController.swift`: SwiftUI 画面のホスト
- `xcode/Passgen/Passgen/AppPreferences.swift`: アプリ全体の設定
- `xcode/Passgen/Passgen/SettingsWindowController.swift`: 設定ウィンドウ
- `xcode/Passgen/Passgen/Base.lproj/Main.storyboard`: メインウィンドウ構成
- `AGENTS.md`: Codex 向けの作業ガイド

## 実行方法

1. `xcode/Passgen/Passgen.xcodeproj` を開く
2. `Passgen` スキームで `Run`
